# Notes

Sure! Here's a list of commonly used Markdown symbols and their uses:

### Headings
```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```
- Use `#` symbols followed by a space to create headings. The number of `#` symbols indicates the level of the heading.

### Bold
```markdown
**Bold Text**
__Bold Text__
```
- Use `**` or `__` around text to make it bold.

### Italic
```markdown
*Italic Text*
_Italic Text_
```
- Use `*` or `_` around text to make it italic.

### Bold and Italic
```markdown
***Bold and Italic Text***
___Bold and Italic Text___
```
- Use `***` or `___` around text to make it bold and italic.

### Strikethrough
```markdown
~~Strikethrough Text~~
```
- Use `~~` around text to strikethrough it.

### Blockquote
```markdown
> Blockquote
>> Nested Blockquote
```
- Use `>` for blockquotes. You can nest blockquotes by using multiple `>` symbols.

### Lists
#### Unordered List
```markdown
- Item 1
- Item 2
  - Subitem 1
  - Subitem 2
```
- Use `-`, `*`, or `+` followed by a space to create unordered list items. Indent to create subitems.

#### Ordered List
```markdown
1. Item 1
2. Item 2
   1. Subitem 1
   2. Subitem 2
```
- Use numbers followed by a period and a space to create ordered list items. Indent to create subitems.

### Links
```markdown
[Link Text](URL)
```
- Use `[Link Text](URL)` to create a hyperlink.

### Images
```markdown
![Alt Text](Image URL)
```
- Use `![Alt Text](Image URL)` to embed an image.

### Code
#### Inline Code
```markdown
`Inline Code`
```
- Use `` ` `` around text for inline code.

#### Code Block
<pre markdown="1">
```language
Code Block
```
</pre>
- Use triple backticks (```) followed by the language name for syntax highlighting to create code blocks.

### Horizontal Rule
```markdown
---
***
___
```
- Use `---`, `***`, or `___` on a line by itself to create a horizontal rule.

### Tables
```markdown
| Header 1 | Header 2 |
| -------- | -------- |
| Row 1    | Data 1   |
| Row 2    | Data 2   |
```
- Use `|` to create tables. Separate headers and rows with dashes (`-`).

### Task Lists
```markdown
- [ ] Task 1
- [x] Completed Task
```
- Use `- [ ]` for an incomplete task and `- [x]` for a completed task.

### Footnotes
```markdown
Here is a footnote reference[^1].

[^1]: This is the footnote.
```
- Use `[^1]` to create a footnote reference and `[^1]:` to define the footnote.

### Emphasis with Symbols
- Use `{}` for Literal Translation
- Use `[]` for Idiomatic Translation

```markdown
Mein Name ist Joachim und ich komme aus Berlin.
{Literal Translation}: My name is Joachim and I come from Berlin.
[Idiomatic Translation]: My name is Joachim and I am from Berlin.
```

These symbols and their uses should help you structure your Markdown notes effectively.
