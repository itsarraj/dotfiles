# Luhmann's Zettelkasten Method

## Unique Note Structure
- Used unique identifier on top left
- Title in the middle of card body
- Bottom contains references to related notes
- One idea per card
- Don't copy text, always put contents in own words

## Original Notes Structure

```
0
1
2
3
```

## Branching with Injected Notes
Injected note 1a and 1b between 1 and 2 if side branch was needed
When side branches are needed between notes:

```
0
1-1a
 -1b
2
3
```

## Further Branching
Injected note 1a1 and 1a2 between 1a and 1b if side further side branch was needed
For additional levels of branching:

```
0
1-1a-1a1
    -1a2
 -1b
2
3
```

### Result
This method allows creating infinite chains of related notes.

## Index System

To navigate the web of links, use index of topics to help with navigation, keeping it in a separate system. Only index entry points - the beginning of sequences of cards - not all notes.

The process of navigation and exploring zettelkasten allows surprises to happen. Very often new ideas and unexpected connections emerge from navigating the zettelkasten.

> "Zettelkasten is a tool for my thinking."

## Modular Notes

A single note or file can be kept separately from the rest of notes without much connection. With continuation of ideas, this extends and can become a collection of notes on an individual topic for reference.

Notes become modules that can exist independently. These modules can then be reused in other contexts or to support different arguments.

## Fleeting Notes

Create fleeting notes for reminding yourself about things to take care of later, in small words and sentences.

## Content Processing

It's not beneficial to accumulate information from the internet and books as they build up a large set of information that won't be read again. Instead, make notes (in your own words) from thoughts that originated from reading the information.

If the information is not worth this process, it's not worth storing.

Make scheduled content consumption.

## Tools for Content Management

- **RSS feeds** - for latest updates
- **Read later apps** - Pocket, Instapaper, Wallabag

## PARA Methodology

- **Projects** - Need to complete something, so research and arrange information for that work. Keep researched information organized here.

- **Areas** - Long-term responsibilities and ongoing commitments.

- **Resources** - References for future reference or notes made for later revision.

- **Archive** - Important notes that can't be deleted as they might be needed in the future.
