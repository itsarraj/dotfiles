# Russian D1

Here's a **complete roadmap** to take you from absolute beginner (A0) to advanced proficiency (C1+) using your existing resources, with structured progression and study strategies:

### Phase 0: Absolute Beginner (0 → A1)
**Focus:** Cyrillic mastery + survival phrases
1. **Cyrillic Alphabet (2-3 weeks)**
   - Use `00.How to Pronounce Russian Correctly.pdf` + Audio
   - Practice writing with `Primeros Trazos de Caligrafia Rusa.pdf`
   - Daily Quizlet/Duolingo for letter recognition

2. **Basic Survival Russian**
   - `04.Survival Russian` (Complete conversational course)
   - Learn essential phrases from `97.Russian for Tourists.pdf`

3. **Foundations**
   - Start `02.The New Penguin Russian Course` (Chapters 1-5)
   - Use `40.Russian Foundation Course` for basic structures

**Daily Practice:** 
- 30min alphabet drills + 15min phrase memorization
- Listen to Disney fairy tales audio while reading PDFs

### Phase 1: Elementary (A1 → A2)
**Focus:** Core grammar + 1,000 word vocabulary
1. **Grammar Foundation**
   - Complete `The New Penguin Russian Course`
   - Add `01 Basic Russian A Grammar and Workbook.pdf`

2. **Vocabulary Building**
   - Study top 500 words from `58.Russian Learners' Dictionary`
   - Use `59.Picture Dictionary Russian.pdf` for visual learning

3. **Listening/Speaking**
   - `22.Шкатулочка` graded reader with audio
   - Shadow audio from `04.Survival Russian`

**Key Milestone:** 
- Can handle basic transactions/simple conversations
- Read children's stories like `Белоснежка и семь гномов`

### Phase 2: Pre-Intermediate (A2 → B1)
**Focus:** Verb system + case mastery
1. **Grammar Intensification**
   - `02 Intermediate Russian A Grammar and Workbook`
   - `35.Russian A practical grammar with exercises`
   - Focus on verbs of motion (`36.Russian Verbs of Motion.pdf`)

2. **Authentic Materials**
   - Read `50.Short Stories By Soviet Writers`
   - Watch Soviet cartoons with Russian subtitles

3. **Speaking Practice**
   - Use `24.Let's talk about life` for conversation structures
   - Record yourself using prompts from `19.Let's talk about life`

**Tools:**
- Anki for case endings/verb conjugations
- LanguageExchange.com for weekly conversations

### Phase 3: Intermediate (B1 → B2)
**Focus:** Nuanced grammar + specialized vocabulary
1. **Advanced Grammar**
   - `19.A Comprehensive Russian Grammar`
   - `47.Russian Grammar in Exercises (Morphology/Syntax)`

2. **Domain-Specific Russian**
   - Business: `30.Язык бизнесмена 1-3`
   - Literature: `43.Cambridge Intro to Russian Literature`

3. **Media Consumption**
   - Read `22.Читаем российские газеты`
   - Watch Russian news (1TV.ru) with transcript analysis

**Writing:**
- Start journaling using `30.Справочник по стилистике`
- Join Russian Reddit communities (r/russian)

### Phase 4: Upper-Intermediate → Advanced (B2 → C1+)
**Focus:** Academic/professional mastery
1. **Linguistic Refinement**
   - `20.A Reference Grammar of Russian (Cambridge)`
   - `06 Синтаксис сложноподчинённого предложения`

2. **Specialized Texts**
   - Analyze `The Cambridge History of Russia` texts
   - Translate academic papers using `40.Russian Translation Theory`

3. **Cultural Nuances**
   - Study `100.Dermo!` for slang mastery
   - Read full novels (start with Чехов short stories)

**Professional Preparation:**
- Practice TORFL-style tests from `78.Тесты, тесты, тесты...`
- Simulate formal presentations using `42.Стилистика русского языка`

### Pro Tips:
1. **Immersion Schedule:**
   - Morning: Grammar drills (30min)
   - Afternoon: Active reading (1hr)
   - Evening: Listening practice (30min) + conversation (30min)

2. **Resource Sequencing:**
   ```mermaid
   graph LR
   A[Penguin Course] --> B[Basic Russian Workbook]
   B --> C[Comprehensive Grammar]
   C --> D[Reference Grammar]
   ```

3. **Progress Tracking:**
   - Monthly: Record 2min self-introduction video
   - Quarterly: Take mock TORFL tests from `78.Тесты...`
   - Biannually: Translate newspaper article → compare with professional translation

4. **Tech Stack:**
   - Speech: Forvo.com (pronunciation verification)
   - Writing: Gramota.ru (reference site)
   - Reading: Readlang (web reader)

This structured approach using your existing resources should get you to C1 in 18-24 months with 1.5hr daily study. Focus on cycling through materials - complete 70% of one resource before moving to next complementary material.
